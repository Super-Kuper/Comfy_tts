# Model manifest for the video_gen TTS serverless worker (Qwen3-TTS + GigaAM-v3).
#
# Format (tab-separated):
#   <path under MODELS_ROOT>\t<URL>\t<sha256>\t<version>\t<license>\t<role>
#
# role: engine   — the TTS weights whose sha256 becomes telemetry.model_hash and
#                  whose license becomes telemetry.license (exactly one row);
#       aligner  — the GigaAM-v3 weights that power words/WER (exactly one row);
#       support  — config/tokenizer support files of either model (0..n rows).
#
# Consumed by populate-volume.sh (or by the service's runpod.provision): files
# land in <MODELS_ROOT>/<path>, e.g. /runpod-volume/models/qwen3-tts-1.7b/model.safetensors.
# Every URL is pinned to an immutable Hugging Face commit revision (LFS oid =
# sha256); `main` is forbidden and populate-volume.sh rejects non-pinned URLs.
# Weights are never baked into the image or committed to git (see .gitignore).
#
# Volume budget: Qwen3-TTS 1.7B ~3.86 GB + speech tokenizer ~0.68 GB,
# GigaAM-v3 ~0.45 GB, tokenizers/configs ~0.03 GB → ~5.1 GB; attach at least
# 15 GB (ComfyUI-free image, outputs/temp and future voices need headroom).
#
# Chatterbox (if the pilot ever asks for it) is a SEPARATE image/stand with its
# own manifest, not a row here: one worker = one engine (contract §1.1).
